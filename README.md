# Elite Canvas

Elite Canvas is a modern e-commerce web application built with Laravel and Blade, featuring a fully functional storefront, core product browsing, and seamless cart/checkout workflows.

## Features
* **Storefront & Product Catalog:** Dynamic product listing and detailed view management.
* **Cart & Checkout Workflows:** Secure cart management and streamlined order processing.
* **MVC Architecture:** Clean separation of business logic, database routing, and presentation layers using Laravel Eloquent ORM.

## Tech Stack
* **Backend:** PHP, Laravel Framework
* **Frontend:** Blade Templating, HTML5, CSS3, JavaScript
* **Database:** MySQL
